# Project Name

## Working Name

**Inkforge Firmware**

## Rationale

- It signals that this is a crafted, performance-focused fork of CrossPoint for the Xteink X4.
- It is short, memorable, and still clear that this is firmware.
- It leaves room for future branding (`Inkforge Core`, `Inkforge Sync`, etc.).

## Scope of Name

- Keep upstream project attribution in all docs and release notes.
- Use `Inkforge Firmware` for this fork's roadmap, PRDs, and release branches.
